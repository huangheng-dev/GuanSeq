# 业务切片：订单成本利润

> 状态：已实现并通过自动化验证  
> 范围日期：2026-08-20

## 1. 业务目标

在销售订单已经发生合格成品出库后，按订单生成不可直接修改的利润快照，闭环第一条制造主流程：

```text
销售订单 → 计划/MRP → 采购与备料 → 生产工单 → 工序执行 → 质量检验 → 完工入库 → 发货 → 成本利润
```

利润结算以销售订单已发数量确认未税收入，以生产实际领退料净数量和财务维护的有效标准成本结转直接材料成本；人工按已审核实际人工分钟归集，制造费用按已完工工序冻结的标准分钟归集，两者使用完工日生效的工作中心费率。

## 2. 模块所有权

- `finance` 模块拥有订单利润结算单、结算行、物料标准成本、工作中心成本费率和结算事件。
- `sales` 模块拥有销售订单、订单行、累计已发数量和订单履约状态；财务只通过销售公开查询 API 读取，不直接写销售表。
- `production` 模块拥有生产订单、合格入库量和实际领退料证据；财务只通过生产公开成本查询 API 读取，不直接写生产表。
- `warehouse` 模块继续拥有库存余额与不可变流水；财务不直接修改库存事实。

## 3. 对象与状态

### 物料标准成本

- 按租户、物料和生效日期维护，同一物料同时只有一条 `ACTIVE` 标准成本。
- 金额使用 `NUMERIC(18,6)`，结算金额使用 `NUMERIC(18,2)`。

### 订单利润结算单

- 编号：`OP-yyyyMMdd-xxxxxx`
- 状态：`SETTLED`
- 成本状态：
  - `COMPLETE`：收入、生产订单、合格入库、实际领料、标准成本、已完工工序和生效费率证据完整。
  - `MISSING_COST`：订单已发货但缺少部分成本证据；快照仍保存，并在 `missingItems` 中明确缺口。

结算单行记录销售订单行、发货数量、生产订单、合格入库数量、实际消耗数量、收入、材料成本、人工成本、制造费用、加工成本、总成本、毛利和成本证据明细。

## 4. 权限与审计

- 生成结算允许角色：`FINANCE_MANAGER`、`ADMIN`。
- 结算动作必须带 `X-Request-Id`；重复请求编号返回同一结算单，不重复生成快照。
- 每个销售订单只允许一版利润结算；重复结算请求返回已有结果。
- 结算事件记录操作者、请求编号、前后状态、收入、材料成本、人工成本、制造费用、加工成本和毛利。

## 5. 关键不变量

- 只有 `PARTIALLY_SHIPPED` 或 `SHIPPED` 销售订单可以结算。
- 结算只统计累计已发数量大于 0 的订单行。
- 收入 = Σ(已发数量 × 订单行未税单价)。
- 直接材料成本 = Σ(实际领退料净用量 × 有效标准成本) ÷ 生产合格入库数量 × 本次已发数量。
- 标准工序分钟 = 准备分钟 + 单位运行分钟 × 工序实际完工数量。
- 人工成本 = Σ(已审核实际人工分钟 ÷ 60 × 完工日有效人工小时费率) ÷ 生产合格入库数量 × 本次已发数量。
- 制造费用 = Σ(标准工序分钟 ÷ 60 × 完工日有效制造费用小时费率) ÷ 生产合格入库数量 × 本次已发数量。
- 加工成本 = 人工成本 + 制造费用；完工日目前统一按 UTC 日期选择生效费率。
- 发货数量不能超过生产合格入库数量；否则标记为缺成本证据。
- 缺少生产订单、合格入库、领料记录、标准成本、已完工工序、已审核实际工时或有效工作中心费率时，不伪造成本，结算状态标记为 `MISSING_COST`；已具备证据的成本项仍独立计算。
- 工作中心费率币种必须与销售订单币种一致；当前切片不做汇率换算。
- 结算快照不回写销售、生产、库存或采购事实，不作为应收应付凭证。

## 6. 异常与恢复

- 无权限返回 403。
- 订单未发货或没有可结算已发数量返回 422。
- 结算不存在或不在当前租户范围返回 404。
- 请求编号或唯一结算冲突返回 409；重复请求按幂等返回已有结果。
- 成本证据缺口不返回失败，而是生成 `MISSING_COST` 快照，便于业务补齐领料、生产入库或标准成本后追查；后续反记账、期间重算和成本调整由专门财务切片处理。

## 7. 前端接入

- `/finance/order-profit` 使用真实后端 API。
- 页面只通过 `src/services/order-profit-server-service.ts`、`src/services/order-profit-client-service.ts` 与同源 BFF Route Handler 访问后端。
- 支持查看待结算发货订单、生成结算、按成本状态筛选，并展示收入、材料成本、人工、制造费用、加工成本、毛利、毛利率和缺成本证据。

## 8. 自动化覆盖

`FinanceOrderProfitIntegrationTest` 覆盖：

1. 已下达销售订单登记发货后生成结算，校验收入、材料成本、人工、制造费用、毛利、毛利率、生产订单和合格数量。
2. 重复 `X-Request-Id` 幂等返回同一结算单。
3. 未发货订单结算返回 422。
4. 无权限角色返回 403。
5. 缺少生产证据或已审核实际工时时生成 `MISSING_COST` 快照，返回明确缺口并保留可计算的其他成本。

## 9. 非目标

- 不实现总账凭证、成本期间结账、差异分摊、设备折旧和外协加工成本。
- 不把工序实际开始/结束时间直接当作财务工时；人工只采用已审核实际工时记录，制造费用继续采用工艺任务冻结的标准分钟。
- 不支持随意删除或编辑利润快照；后续错误通过冲销/调整单据处理。
- 已生成结算保持不可变；本次口径升级不自动重算历史快照。
- 不把前端按钮作为权限边界，所有授权均在后端校验。
