# 业务切片：生产订单计划接收与 MRP 净需求

## 目标

把生产订单从通用前端页面推进为生产模块拥有的受控业务事实，并让计划模块同时冻结库存、采购在途和生产在制供给，执行可追溯的时间分段净需求运算。本切片生成计划建议，但不绕过采购或生产状态机直接创建下游订单。

## 业务对象与所有权

| 对象 | 所有模块 | 说明 |
|---|---|---|
| 生产订单 | 生产 | 保存自制物料、计划数量、完工数量、计划日期、车间、责任人与来源 |
| 有效 BOM 结构 | 产品 | 通过公开接口向计划模块提供父项基数、组件数量和损耗率 |
| 生产计划接收 | 生产 | 只公开已下达或执行中且尚未完工的数量 |
| MRP 净需求结果 | 计划 | 冻结毛需求、库存消耗、计划接收消耗、净需求、建议类型与日期 |

计划模块不得直接查询生产表或产品表；生产模块不得写计划结果。模块间分别通过 `ProductionScheduledReceiptProvider`、`BomReferenceProvider` 和既有库存、采购公开接口协作。

## 状态与规则

生产订单状态：`DRAFT → RELEASED → IN_PROGRESS → COMPLETED`。草稿和未开工的已下达订单允许取消为 `CANCELLED`。`COMPLETED` 不再是人工状态动作，只能由“生产报工 → 完工检验 → 合格品入库”结算到计划数量后自动形成。

- 只有自制物料可以建立生产订单。
- 草稿允许编辑；下达后锁定计划业务内容。
- 下达时必须存在计划开工日已生效的 BOM 和工艺路线。
- 已下达和执行中订单的 `planned_quantity - completed_quantity` 作为生产计划接收；`reported_quantity` 单独表示已报工但尚未结算的在检数量。
- 完成或取消订单不再提供 MRP 计划接收。
- 取消必须填写原因；所有状态动作保留操作者、时间、请求编号和审计事件。
- 所有更新使用版本号检查，不静默覆盖并发修改。

## MRP 净算规则

1. 冻结计划期间内的有效独立需求。
2. 识别有效 BOM 物料层级，并冻结相关物料的库存、采购计划接收、生产计划接收和提前期。
3. 对同一物料按需求日期先后消费可用库存，再消费预计接收日期不晚于需求日期的计划接收。
4. `净需求 = 毛需求 - 库存消耗 - 计划接收消耗`。
5. 净需求大于零时，根据获取方式形成 `PRODUCTION`、`PURCHASE` 或 `OUTSOURCE` 建议，建议下达日期按自然日提前期反推。
6. 自制净需求使用有效 BOM 基数、组件用量与损耗率展开组件毛需求，并按低层码顺序净算。
7. 缺少库存余额事实、提前期、有效 BOM 或工艺路线时，对应结果标记 `BLOCKED` 并生成稳定异常码和处理路径。
8. 零库存、零在途和零净需求都是合法业务结果；仅“从未建立库存余额”属于事实缺失。

当前净算采用物料级自然日提前期和不限批量策略。安全库存、批量规则、工作日历、替代料、损耗舍入策略和建议转单审批，应由后续真实业务需求驱动增量引入。

## 数据与 API

Flyway：

- `V15__create_production_order_model.sql`
- `V16__add_mrp_net_requirement_results.sql`

主要接口：

- `GET/POST /api/v1/production/orders`
- `GET/PUT /api/v1/production/orders/{id}`
- `POST /api/v1/production/orders/{id}/actions`
- `GET /api/v1/production/order-reference-data`
- `GET/POST /api/v1/planning/mrp-runs`
- `GET /api/v1/planning/mrp-runs/{id}`

数据库结构以 Flyway 为事实来源，HTTP 契约以 `guanseq-api-v1.yaml` 为事实来源。

## 前端验收

- `/production/orders/list` 展示真实生产订单，支持筛选、排序、勾选导出、分页、新建、编辑、下达、开工和取消；完工必须进入生产报工链路。
- 生产订单详情明确展示是否进入 MRP、未完工数量、预计接收日期和来源单号。
- `/planning/mrp/runs` 展示净需求结果、库存消耗、采购/生产计划接收消耗、建议类型、建议下达日期和异常证据。
- 页面只通过 `src/services` 和 BFF Route Handler 访问后端。

## 未完成边界

- MRP 建议已支持逐条审核并转为带来源追溯的采购或生产草稿单，详见 [业务切片：MRP 建议审核与转单](./业务切片-MRP建议审核与转单.md)；建议合并、拆分和批量转单尚未接入。
- 生产订单级报工、部分完工、完工检验和合格品入库已由后续切片接入，详见 [业务切片：生产报工、完工检验与成品入库](./业务切片-生产报工、完工检验与成品入库.md)。领退料、工序执行、过程检验、返工返修仍未接入。
- 当前未实现安全库存、最小批量、固定批量、倍量、工作日历、替代料与多工厂调拨建议。
- 生产合格品入库已回写生产订单完成量；采购收货仍未回写采购计划接收完成量。
