# 业务切片：设备接入技术预检证据

> 状态：工程闭环完成（真实现场验收待完成）  
> 日期：2026-08-26  
> 领域归属：`equipment`  
> 前置能力：Modbus TCP 与外部 MQTT 3.1.1 Broker 只读适配、统一连接事件

## 1. 业务目标

设备经理需要在启用采集前确认“当前配置能否通过生产协议适配器读取全部点位”，同时不能把开发仿真或一次连通成功误报为真实现场验收。该切片把现有连接测试升级为结构化技术预检，并将结果写入已有不可变连接事件。

正式接入时仍使用同一连接、点位、协议适配器、OpenAPI 和样本模型；只替换端点、凭据别名和点位/Topic 映射，不使用另一套伪接口。

## 2. 业务对象与数据所有权

| 对象 | 所有者 | 说明 |
|---|---|---|
| 采集连接 | `equipment` | 保存协议、端点类型、只读点位和生命周期 |
| 技术预检证据 | `equipment` 的连接事件 | 复用不可变 `TEST_SUCCEEDED` / `TEST_FAILED` 事件，不新增独立基础设施 |
| 现场验收结论 | 现场责任人与后续受控验收流程 | 本切片永远不自动写入“现场已验收” |

## 3. 动作、状态与不变量

- `DRAFT`、`ACTIVE`、`PAUSED` 均允许连接管理岗位执行技术预检；动作不改变配置状态。
- 只有 `MAINTENANCE_MANAGER`、`ADMIN` 可以执行；普通成员只能读取脱敏后的证据。
- 预检必须使用已注册的生产协议适配器读取全部点位，不生成业务样本，也不修改人工设备运行状态。
- 任一点位缺失、类型不匹配或协议读取失败时，技术预检失败并记录稳定错误码。
- 端点类型为 `SIMULATOR` 时证据级别固定为 `SIMULATION_TECHNICAL`；物理设备或外部 Broker 固定为 `FIELD_CANDIDATE_PRECHECK`。
- 每次结果都固定记录 `fieldAccepted=false`。连通、TLS 配置或全部点位读取成功仍不等于现场验收。
- 事件不得记录密码、用户名、主机、Topic 或消息原文等敏感连接信息。

## 4. 结构化检查

技术预检至少输出：

1. 协议适配器可用性；
2. 端点连通与协议读取；
3. 全部配置点位覆盖；
4. 值类型与映射形态；
5. 值域警告数量；
6. MQTT TLS/凭据别名或 Modbus 网络隔离提示；
7. 仿真/现场候选证据边界；
8. 仍待人工完成的现场资料、网络、安全、断连恢复和容量检查。

## 5. API 与失败恢复

- 继续使用 `POST /api/v1/equipment/telemetry-connections/{id}/test`，保持现有客户端兼容。
- 成功和失败仍返回 `EquipmentTelemetryActionResult`；结构化预检结果进入返回连接的最新事件 `details`。
- 协议失败返回业务结果 `success=false`，运行状态转为通讯失败；修复端点或映射后可重新预检，历史失败事件不覆盖。
- 版本冲突、无权限和工作区越界继续由现有后端边界拒绝。

## 6. 验收条件

1. Modbus 与 MQTT 标准协议仿真均能生成结构化预检通过事件。
2. 无效 JSON、连接失败或点位缺失生成结构化失败事件和稳定错误码。
3. 仿真成功明确显示“仿真技术预检通过，非现场验收”。
4. 现场候选端点即使技术通过，`fieldAccepted` 仍为 `false`。
5. 页面展示检查结果、警告、请求编号和待现场事项，不泄露敏感配置。
6. 普通成员不能执行预检，后端授权仍是唯一可信边界。
7. lint、类型检查、前后端测试、PostgreSQL 集成、生产构建和桌面/390px 浏览器流程通过。

## 7. 非目标

- 不自动签发现场验收证书；
- 不承诺真实 TLS/ACL、网络审批、断连恢复或容量已经通过；
- 不增加内置 Broker、网关、时序数据库或独立接入服务；
- 不实现远程控制、报警、OEE、长期聚合或 MQTT 5 专属能力。

## 8. 工程验证结果

- Modbus 与 MQTT 集成测试均验证成功预检、失败预检、点位覆盖、值类型、警告和 `fieldAccepted=false`；无效 MQTT JSON 与拒绝连接保留稳定错误码和不可变事件。
- OpenAPI、前端 Zod 与 BFF 保持同一结构化预检契约；前端 29 个测试文件、86 项测试通过。
- 后端完整测试 117/117 通过、0 跳过，PostgreSQL 18.4 空库完整执行 V1—V44；本切片复用现有事件 JSON，不新增迁移。
- lint、typecheck 和生产构建通过。
- 浏览器在真实 BFF/API/PostgreSQL 与 MQTT 3.1.1 协议链路完成技术预检，返回 3/3 点位覆盖、0 警告，并明确显示“现场尚未验收”；桌面和 390px 通过，控制台 0 错误、0 警告。
