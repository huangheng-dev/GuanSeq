# 业务切片：供应商主数据（Supplier Master Data）

> 文档状态：已实现并通过测试
> 适用阶段：业务核心底座
> 模块归属：procurement（供应商子域）
> 迁移：V13（建表）、V33（事件表）、V34（乐观锁版本）
> 前置切片：无

## 0. 设计立场

供应商是采购模块拥有的主数据事实，其他模块（财务应付、来料检验、计划接收）通过 procurement 模块的公开 API 引用，不得直接访问供应商表。

供应商维护保持轻量：编码、名称、联系人、电话、状态。不做审批流、不做银行账户、不做绩效评分（绩效为后续规划）。停用后的供应商不能用于新采购订单，但已有订单继续履约。

## 1. 业务对象与事实所有权

| 对象 | 所有者模块 | 说明 |
|---|---|---|
| 供应商 | procurement | 本切片维护 |
| 采购订单 | procurement | 引用供应商，停用供应商不能建新单 |
| 应付发票 | finance | 通过 ProcurementPayableQueryProvider 引用供应商 |
| 租户/工作区 | identity | 供应商按 tenant_organization_id 隔离 |

## 2. 状态机

```
ACTIVE（启用，可用于新采购订单）
  ↔ INACTIVE（停用，不能用于新采购订单，已有订单不受影响）
```

## 3. 业务流程

### 3.1 新建供应商

1. 录入编码（租户内唯一）、名称（必填）、联系人、电话。
2. 角色校验：PROCUREMENT_MANAGER 或 ADMIN。
3. 编码重复返回 409。
4. 写 CREATED 事件。

### 3.2 更新供应商

1. 修改名称、联系人、电话。
2. 必须传 `expectedVersion`，过期返回 409。
3. 写 UPDATED 事件。

### 3.3 启用/停用

1. 传 status 和 expectedVersion。
2. 状态未变化返回 409。
3. 停用后不能新建采购订单（PurchaseOrderApplicationService.create 校验 ACTIVE）。
4. 写 ENABLED / DISABLED 事件。

### 3.4 查询

- 分页列表，支持 query（编码/名称/联系人模糊）和 status 筛选。
- 跨租户不可见（按 tenant_organization_id 过滤）。
- 采购订单参考数据只返回 ACTIVE 供应商。

## 4. 权限

| 操作 | 允许角色 |
|---|---|
| 查询 | 已认证用户 |
| 新建/更新/启停 | PROCUREMENT_MANAGER, ADMIN |

## 5. 并发与审计

- `@Version` 乐观锁（V34 加列），更新和状态变更必须传 expectedVersion。
- 所有写操作记录到 `procurement.supplier_events`，含 actor、request_id、action、details。
- 事件类型：CREATED、UPDATED、ENABLED、DISABLED。

## 6. Flyway 迁移

### V13 procurement.suppliers（原有）

核心列：id、tenant_organization_id、owning_organization_id、code、name、contact_name、contact_phone、status、created_by/at、updated_by/at。
唯一约束：UNIQUE(tenant_organization_id, code)。


## 7. OpenAPI 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/v1/procurement/suppliers | 分页查询（query/status/page/size） |
| POST | /api/v1/procurement/suppliers | 新建 |
| PUT | /api/v1/procurement/suppliers/{id} | 更新（需 expectedVersion） |
| POST | /api/v1/procurement/suppliers/{id}/actions | 启用/停用（需 expectedVersion） |

## 8. 前端接入

- 导航：采购域 → 供应商 → 供应商列表（路径 `/procurement/suppliers/list`）。
- 复用 BusinessWorkspace 的目录布局和表单弹窗，通过 master-data-server-service 的 supplier 分支接入。
- BFF：`/api/masterdata/mutate` 扩展 `/procurement/suppliers/list` 路径。
- 列表页显示：编码、名称、联系人、联系电话、状态。
- 停用/恢复走批量操作，逐条调用 `/actions` 并传当前 version。

## 9. 验收条件

1. 列表只显示当前租户供应商，隔离租户 SUP-HIDDEN 不可见。
2. 新建供应商成功并写 CREATED 事件。
3. 重复编码返回 409。
4. 更新供应商成功并写 UPDATED 事件。
5. 过期 expectedVersion 返回 409。
6. 停用供应商后新建采购订单返回 422。
7. 低权限角色（如 PROCUREMENT_BUYER）写操作返回 403。
8. 跨租户更新/启停返回 404。
9. 审计事件 CREATED/UPDATED/DISABLED/ENABLED 完整记录。
