## 1. 决策摘要

以开发种子设备 `EQ-CNC-001` 为仿真对象，假设一台 Modbus TCP 设备、8 个只读点位，完成协议形态、点位字典、容量、权限、可靠性和验收路径评审。该结果只证明设计可以进入技术评审，不证明真实 PLC 可连接、地址正确、网络获批或现场验收通过。

在当前假设规模下，第一切片复用现有 Spring Boot 模块化单体和 PostgreSQL，暂不引入现场边缘网关、EMQX、TimescaleDB、独立设备接入服务或新的消息组件。浏览器只通过 HTTPS 业务 API 读取数据；首个切片不包含远程控制、参数下发、OEE、预测维护和自动创建维修工单。

在厂商寄存器表、真实网络参数、最小权限交付和可测试端点到齐之前，已按 [ADR-0006](./adr/0006-无真机条件下的可替换设备采集闭环.md) 实现统一协议适配接口、生产 Modbus TCP 适配器和外部仿真端点闭环。该结果必须标记为仿真验证，不得宣称完成真实现场接入；`/equipment/telemetry` 现已从纯规划页调整为“标准协议仿真已验证、现场验收待完成”。

## 3. 容量评审

容量公式与输入保存在工作簿中，结果如下：

| 场景 | 设备/点位 | 总样本/日 | 平均样本/秒 | 原始保留量 | 离线缓存样本 | 要求补传样本/秒 |
|---|---:|---:|---:|---:|---:|---:|
| 首机平均 | 1 / 8 | 104,180 | 1.21 | 1.16 GB / 30 天 | 34,727 | 19.29 |
| 试点峰值 | 5 / 20 | 6,922,000 | 80.12 | 104.44 GB / 30 天 | 6,922,000 | 1,922.78 |
| 未来 12 个月 | 20 / 30 | 20,756,000 | 240.23 | 313.15 GB / 30 天 | 20,756,000 | 2,882.78 |

首机平均场景不足以证明需要新增基础设施，因此只批准受限单机试点的模块内实现。峰值和未来 12 个月场景是架构复评触发参考，不是容量承诺，也不是自动采用某个组件的结论。

出现以下任一经真实压测或现场约束确认的情况时，先创建 ADR，再决定是否调整架构：

- 持续写入超过 100 样本/秒，或原始保留量超过 50 GB，且 PostgreSQL 基准测试不能满足写入、查询、备份和恢复目标。
- 现场必须隔离运行、必须支持串口/专有驱动，或断网缓存不能由中心模块可靠承担，需要评估边缘网关。
- 多网关长连接、离线会话和发布订阅成为实际需求，需要评估 MQTT Broker。
- 协议依赖、故障隔离或独立扩缩容已经影响现有模块化单体，需要评估独立接入服务。

这些阈值仅触发问题复核；任何组件仍须记录问题证据、成本、运维责任、退出条件和验证方式。

## 4. 最小纵向切片

真实资料通过准入评审后，按以下顺序实现：

```text
现有设备台账
→ 受控连接配置（只读、密钥不回传）
→ 单一 Modbus TCP 适配器
→ 3–10 个已确认点位
→ 样本归一化与去重
→ 当前值和有限历史
→ 工作区权限下的只读 API 与页面
→ 通讯、质量、失败和人工处置证据
```

统一样本至少包含：租户/工作区、设备 ID、点位编码、原始值与归一化值、工程单位、质量、设备时间（可空）、接收时间、接收序列、消息版本和来源连接。连接状态、数据质量和人工维护的设备业务状态是三个不同事实，不允许互相覆盖。

`equipment` 模块拥有设备身份、连接配置和采集用例；原始遥测不直接修改设备、生产、质量或维修事实。未来报警需要通过已授权业务 API 和明确的人工/自动规则建立关联，不能绕过模块边界写表。

## 5. 权限、并发与审计

- 平台管理员或现场运维管理密钥引用；API 和页面不返回明文密钥。
- 设备经理查看连接、通讯和质量证据；维修、生产岗位仅查看其工作区授权点位。
- 后端校验租户、工作区和角色；前端隐藏入口不构成授权。
- 配置变更使用乐观版本和请求幂等，记录责任人、时间、来源、请求编号和差异。
- 样本去重键由真实协议能力评审确定；工程候选为“设备 + 点位 + 接收序列”，不得在没有设备序列时虚构设备时间唯一性。

## 6. 可执行验收矩阵

真实端点到齐后至少验证：

1. 正常连接、读取、归一化、存储和只读展示。
2. 超时、协议异常、越界和无效值分别映射为可解释质量，不污染业务状态。
3. 设备断连、网络断开、重连、缓存补传和恢复时间达到现场目标。
4. 重复、乱序和时钟漂移不会重复产生样本副作用或业务动作。
5. 未授权角色、跨工作区和跨租户访问由后端拒绝；密钥不会进入响应、日志或截图。
6. 配置并发修改返回冲突；同一请求编号重试保持幂等。
7. 真实写入量、趋势查询、30 天保留、备份和恢复通过基准测试。
8. OpenAPI、Flyway、自动化测试、生产构建、现场联调和浏览器验收全部通过。
