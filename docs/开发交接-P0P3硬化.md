## 下一步主线

1. **预防性维护模板、到期任务生成与逾期证据**：定义周期、提前期、责任人与适用设备；首版由人工触发按日期幂等生成点检/保养工单，避免为一个定时动作提前引入独立调度服务。
2. **设备采集需求审计**：只有拿到具体设备、协议、点位频率、断连补传和报警需求后，才设计网关与遥测切片；EMQX、TimescaleDB 和独立设备接入服务继续受 ADR 门禁约束。
3. **阶段 C 增强项**：红字/反核销、暂估应付、移动作业等按试点优先级逐项形成纵向闭环，不与设备主线混做。
4. **跨模块统一审计查询**：在多个不可变事件表已经稳定后，再设计只读聚合 API 和统一审计视图，不改变各模块事实所有权。
