# 产品 BOM 版本业务切片

> 交付状态：已实现并接入真实 API  
> 生效日期：2026-08-15

## 业务目标

产品工程与计划人员以同一受控 BOM 版本描述自制物料的生产结构。计划模块只按需求日期引用已经发布且生效的版本，草稿和停用版本不进入 MRP 前置条件判断。

## 事实归属与边界

- `product` 模块拥有 BOM 表头、组件明细、版本状态和变更证据。
- `masterdata` 模块继续拥有物料；产品模块只通过 `MasterDataReferenceProvider` 校验并冻结物料快照。
- `planning` 模块只通过 `BomReferenceProvider` 查询指定日期是否存在有效 BOM，不直接读取 `product` 表。
- 本切片不包含替代料、工艺路线、工程变更审批、完整 BOM 展开、库存净需求或供需建议。

## 对象与状态机

```text
草稿 DRAFT
  ├─ 编辑（仅草稿，必须携带 expectedVersion）
  └─ 发布 → 已发布 PUBLISHED
                  └─ 停用 → 已停用 INACTIVE
```

已发布和已停用版本不可直接编辑；需要修订时创建新版本。停用不会删除历史结构和审计证据。

## 业务不变量

- 父项必须是当前租户内启用的自制物料。
- BOM 至少包含一条启用组件；组件用量大于零，损耗率在 `[0, 1)`。
- 同一 BOM 内组件不能重复，父项不能直接引用自身。
- 发布时检查现有已发布结构，拒绝形成多层循环引用。
- 同一租户、父项和生产用途同时只能存在一个已发布版本；发布新版本前必须停用旧版本。
- 父项、用途和版本编码组合唯一；所有编辑使用乐观锁，冲突不静默覆盖。
- 创建、更新、发布与停用记录操作人、工作区、时间、请求编号和状态变化。

## 权限

`PRODUCT_ENGINEER`、`PLANNING_MANAGER` 和 `ADMIN` 可以维护 BOM。读取仍受当前租户和工作区身份边界控制；后端授权是唯一可信边界。

## 验收结果

- Flyway `V8` 创建 `product.boms`、`product.bom_lines`、`product.bom_events` 和约束/索引。
- OpenAPI 已定义分页、详情、创建、更新、发布/停用和参考物料接口。
- `/product/boms/list` 已使用真实服务，覆盖加载失败、空数据、筛选、排序、选择、导出、完整分页、草稿表单、动态组件行、详情与状态确认。
- PostgreSQL 集成测试覆盖租户隔离、权限拒绝、自引用、发布冲突、乐观锁和审计请求号。
- MRP 准备检查已按需求日期识别有效 BOM；库存供给位置与提前期仍是独立阻断项。
