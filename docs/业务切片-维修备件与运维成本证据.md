# 业务切片：维修备件与运维成本证据

> 文档状态：已完成
> 适用阶段：设备与智能能力（阶段 D 第三个纵向切片）
> 模块归属：equipment；库存事实归属 warehouse；标准成本归属 finance
> 迁移：V39
> 前置切片：设备点检、保养与维修闭环

## 0. 业务目标与非目标

本切片把备件台账、仓库可用量、维修领用/退回、人工投入和运维成本快照接到维修工单证据链。维修人员在工单执行中领用备件、退回未使用数量并登记人工投入；验收人员可以看到净备件成本、人工估算成本、总运维成本及每笔来源。

本切片不实现财务记账、工资、总账凭证、采购补货建议、外协维修结算、序列号备件、周期计划、IoT、报警、OEE 或远程控制。人工费率由录入人作为本次运维估算快照提交，界面与 API 均不得把它宣称为工资或财务凭证。

## 1. 对象与数据所有权

| 对象 | 所有者 | 规则 |
|---|---|---|
| 备件台账 | equipment | 关联一项有效物料，冻结物料编码、名称、规格、单位和默认仓库快照 |
| 库存余额与流水 | warehouse | equipment 只能通过公开库存服务查询可用量并提交领退，不直接访问仓储表 |
| 物料标准成本 | finance | equipment 只能通过公开成本查询读取生效成本；领用时冻结成本和币种 |
| 维修备件事务 | equipment | `ISSUE` / `RETURN` 不可变证据；退回必须引用原领用事务 |
| 维修人工事务 | equipment | `ENTRY` / `REVERSAL` 不可变估算证据；冲销必须引用原登记 |
| 维修工单 | equipment | 汇总净备件成本、净人工成本和总运维成本，不回写财务模块 |

一项物料在同一工作区只能建立一条启用备件台账。备件台账不复制库存数量；列表中的可用量每次从仓储模块读取。

## 2. 状态与动作门禁

- 只有 `REPAIR` 且状态为 `IN_PROGRESS` 的工单可以领用、退回、登记或冲销人工。
- 送验、验收和已完成状态只读；验收驳回回到 `IN_PROGRESS` 后可以继续追加证据。
- 领用数量必须大于零，所选仓库的合格可用库存必须足够，并且领用时必须存在有效标准成本。
- 退回数量必须大于零，仓库必须与原领用一致，累计退回不能超过原领用数量；退回沿用原领用的单位成本与币种，金额冲减成本。
- 人工小时和小时费率必须大于零。错误登记只能通过一次性冲销保留原始证据，不能编辑或删除。
- 每个写动作携带工单 `expectedVersion` 和 `X-Request-Id`，成功后推进工单版本；重复请求返回原结果，不重复扣库存或记成本。

## 3. 权限与范围

| 操作 | 允许角色 |
|---|---|
| 查询备件、可用量、工单成本证据 | 当前工作区已认证用户 |
| 建立备件台账、领用/退回、登记/冲销人工 | `MAINTENANCE_MANAGER`、`PRODUCTION_MANAGER`、`ADMIN` |

后端按当前租户和工作区校验备件与维修工单。跨租户、跨工作区对象按不存在处理；前端隐藏按钮不构成授权。

## 4. 成本口径

```text
净备件成本 = Σ领用数量×领用日有效标准成本 - Σ退回数量×原领用成本
净人工估算 = Σ人工小时×录入小时费率 - Σ已冲销人工金额
运维成本合计 = 净备件成本 + 净人工估算
```

金额按币种分别记录。本切片只允许同一维修工单使用同一币种；首版本地数据为 CNY。标准成本缺失时拒绝领用，避免把未知成本默认为零。

## 5. API 契约

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/equipment/spare-parts` | 当前工作区备件、默认仓库可用量与标准成本 |
| GET | `/api/v1/equipment/spare-parts/references` | 有效物料、仓库和库位引用 |
| POST | `/api/v1/equipment/spare-parts` | 建立备件台账 |
| POST | `/api/v1/equipment/work-orders/{id}/spare-issues` | 执行中维修工单领用备件 |
| POST | `/api/v1/equipment/work-orders/{id}/spare-returns` | 按原领用事务退回备件 |
| POST | `/api/v1/equipment/work-orders/{id}/labor-entries` | 登记人工投入与费率快照 |
| POST | `/api/v1/equipment/work-orders/{id}/labor-entries/{entryId}/reversals` | 冲销错误人工登记 |

维修工单详情返回备件事务、人工事务、净成本合计和可执行成本动作。

## 6. 验收条件

1. 备件可用量来自 warehouse，标准成本来自 finance，equipment 不直接访问其他模块表。
2. 领用同时生成仓库 `ISSUE` 流水与设备备件事务，任一步失败整体回滚。
3. 退回生成仓库 `RETURN` 流水，累计退回不能超过原领用数量，成本按原快照冲减。
4. 非执行中维修工单、无权限角色、过期工单版本、重复请求和库存不足分别返回明确的 403/409/422 语义。
5. 人工登记与冲销不可变、可追责，成本口径明确标记为运维估算。
6. 前端 `/equipment/spare-parts` 替换 Mock，并在维修工单详情完成领退、人工登记/冲销和成本证据查看。
7. Flyway、OpenAPI、模块边界、后端集成测试、前端契约测试、lint、类型检查、生产构建与真实浏览器流程全部通过。
