# 业务切片：可替换 Modbus TCP 只读采集

> 状态：代码、标准协议仿真、PostgreSQL 集成与浏览器闭环验证完成；真实设备与现场验收待完成  
> 目标：没有真机时用外部协议仿真端点完成生产形态验证；用户取得真机后只替换配置即可接入  
> 领域所有者：`equipment`  
> 架构决策：[ADR-0006](./adr/0006-无真机条件下的可替换设备采集闭环.md)

## 业务目标

设备经理需要把设备台账中的一台设备配置为只读 Modbus TCP 数据源，验证连接和点位后启用采集，并查看当前值、数据质量、通讯状态和最后成功时间。生产、维修等获授权岗位只读查看，不管理网络连接。

## 业务对象与状态

- 设备连接：`DRAFT → ACTIVE ↔ PAUSED`。新连接先测试，最近一次测试成功后才能启用；暂停保留历史证据。
- 通讯状态：`UNKNOWN / ONLINE / OFFLINE`，独立于连接配置状态和人工设备运行状态。
- 点位：属于连接，首期支持线圈和保持寄存器的只读值，不包含写功能码。
- 数据质量：`GOOD / UNCERTAIN / BAD`。协议读取成功且值域合法为 GOOD，越界为 UNCERTAIN，通讯或协议失败由连接运行状态记录为 OFFLINE。

## 权限与所有权

- `equipment` 拥有连接、点位、采集样本和运行状态表。
- `ADMIN`、`MAINTENANCE_MANAGER` 可以创建、测试、启用、暂停和立即采集。
- 当前工作区成员可以读取本工作区连接和当前值；跨工作区、跨租户均返回不存在。
- 连接端点只向有管理权限的岗位返回；浏览器仅调用 HTTPS 业务 API。

## 首期范围

- 一台设备、一条 Modbus TCP 连接、3–10 个只读点位。
- 连接测试、人工立即采集、受控周期采集、样本留存和当前值展示。
- `BOOLEAN`、`UINT16`、`INT16`、`UINT32` 和 `INT32`，支持比例、偏移与合法范围。
- 外部标准协议仿真端点与真机使用相同适配器。

## 非目标

- 不支持远程控制、寄存器写入、参数下发和安全联锁。
- 本切片不实现 OPC UA、MQTT、串口 Modbus RTU、OEE、自动维修工单和预测维护；MQTT 是后续共享统一样本模型的协议适配器，不是被排除的产品能力。
- 不宣称完成真实厂商、网络、安全、容量或现场验收。
- 不引入 Broker、时序数据库、独立接入服务或强制边缘代理。
- 不承诺原始样本查询、聚合和自动保留清理；这些能力需由真实查询与保留要求驱动后续切片。

## 验收条件

1. Flyway 是连接、点位、运行状态、样本和审计表的唯一事实来源。
2. OpenAPI 覆盖列表、详情、创建、测试、启停、立即采集和当前值。
3. 成功采集保存设备、点位、值、质量、接收时间、序列号和协议来源。
4. 连接失败不会修改人工设备运行状态，也不会生成虚假的 GOOD 样本。
5. 只有最近测试成功的连接可以启用；版本冲突返回 409。
6. 读取和管理权限、工作区隔离及端点字段权限由后端验证。
7. 自动化测试使用外部协议端点覆盖正常值、越界值、断连和异常响应。
8. 页面明确标注数据来源和真实现场验收状态，覆盖加载、空数据、失败、无权限和操作中状态。

## 当前验证结果

- Flyway V41、OpenAPI、Spring Modulith 内的连接/点位/运行状态/样本/事件模型、真实 TCP Modbus 只读适配器、受控轮询和前端工作台均已实现。
- 标准协议仿真端点已返回功能码 03 的真实 Modbus TCP 响应；适配器单元测试覆盖正常读数和协议异常。
- 前端 lint、TypeScript、81 项测试与生产构建通过；后端完整 111 项测试、架构测试、OpenAPI 契约测试和 Modbus 协议测试通过。
- 已在 PostgreSQL 18.4/Testcontainers 下从空库完整执行 V1—V41，`EquipmentTelemetryIntegrationTest` 覆盖成功、断连、权限与分页契约；完整后端测试为 111/111 通过、0 跳过。
- 已通过浏览器完成“创建连接 → 测试通讯 → 启用 → 立即采集 → 查看归一化值 → 暂停”闭环，并保留连接事件与采集样本；测试值为 `RUN_STATE=2`、`SPINDLE_LOAD=68.5%`、`DOOR_CLOSED=true`。
- 真实设备寄存器表、网络审批、安全交付、断连恢复、容量和现场责任仍待试点方验证；仿真通过不等于真实现场启用。
