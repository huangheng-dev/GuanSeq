# 业务切片：采购退货与供应商处置闭环

> 适用阶段：阶段 C 订单到交付反向增强  
> 工程状态：已闭环（2026-08-27）  
> 前置事实：采购收货与来料检验、库存流水、采购应付红字与退款、暂估应付

## 目标与边界

```text
采购收货/IQC 已形成 AVAILABLE 或 BLOCKED 库存
→ 采购经理建立供应商退货授权
→ 仓库按原收货批次过账退回出库
→ 合格品退回减少采购订单净合格收货，隔离品退回不改变合格收货
→ 未开票额度与后续暂估按净合格收货重算
→ 已开票超过净合格收货时，应付发票标记“采购退货待复核”
→ 财务人员在既有红字发票/供应商退款流程独立确认资金事实
```

本切片不自动生成应付红字发票或供应商退款，不把实物离库等同于供应商已经确认扣款或返款。

## 业务对象与所有权

| 对象 | 所有模块 | 核心事实 |
| --- | --- | --- |
| 采购退货单、退货行与责任事件 | procurement | 原订单/收货行、质量状态、授权与实发数量、状态、原因和证据 |
| 毛合格收货、累计合格退货、净合格收货 | procurement | 净合格收货 = 毛合格收货 − 累计合格退货 |
| 退回出库与冲回入库流水 | warehouse | 精确余额、仓库、库位、批次、质量状态和不可变流水 |
| 应付退货影响标记、红字、退款 | finance | 已开票是否超过净合格收货；红字和资金动作仍由财务确认 |

模块只通过公开 API 或同步模块事件协作，不跨模块修改表。

## 状态机

```text
PENDING_SHIPMENT ──退回出库──> SHIPPED ──冲回出库──> REVERSED
       └──取消授权──> CANCELLED
```

- `PENDING_SHIPMENT`：采购已经授权，库存尚未离库。
- `SHIPPED`：所有授权行按原批次从 `AVAILABLE` 或 `BLOCKED` 出库。
- `CANCELLED`：出库前取消并释放占用的可退数量。
- `REVERSED`：发现出库登记错误，将同批次同质量状态库存完整回补并恢复净合格收货。

首版一张退货单一次完整出库，不做分批发运。冲回后原单终结，后续正确业务重新建单。

## 权限与不变量

- `PROCUREMENT_MANAGER`、`ADMIN` 可以建立或取消退货授权。
- `WAREHOUSE_MANAGER`、`INVENTORY_CONTROLLER`、`ADMIN` 可以退回出库或冲回。
- 退货只能引用当前租户已完成结算的采购收货行及其 `AVAILABLE`/`BLOCKED` 余额。
- 单行数量大于零；历史未取消/未冲回退货加本次授权不得超过该收货行对应质量数量。
- 出库时重新校验精确余额、质量状态、未分配/未冻结可用量，库存不足返回 422，不产生部分过账。
- `AVAILABLE` 出库增加订单行累计合格退货；`BLOCKED` 出库不改变合格收货或应付口径。
- 退货后允许重新接收替换品，但净合格收货不得超过订单数量或小于零。
- 写动作使用 `X-Request-Id` 幂等并校验 `expectedVersion`；事件记录责任人、时间、原因、请求编号和前后状态。
- 已开票净数量超过采购订单净合格收货时，相关应付发票标记 `REVIEW_REQUIRED`；财务完成足额红冲或退货冲回后自动清除标记。

## API 与完成定义

- `GET /api/v1/procurement/returns`
- `GET /api/v1/procurement/returns/{id}`
- `GET /api/v1/procurement/return-reference-data`
- `POST /api/v1/procurement/returns`
- `POST /api/v1/procurement/returns/{id}/actions`
- Flyway `V49` 是表结构事实来源，OpenAPI 是 HTTP 契约事实来源。
- PostgreSQL 集成测试覆盖合格退货出库/冲回与应付复核、隔离库存退回不改变净合格收货，以及超退、越权和取消授权；既有平台回归继续覆盖请求幂等与乐观并发基础能力。
- `/procurement/returns` 通过 `src/services` 和同源 BFF 接入真实 API，覆盖加载、空、无权限、校验、失败、提交中和冲突。
- lint、类型检查、前后端全量测试、生产构建、V1—V49 迁移及桌面/390px 浏览器闭环通过。

## 非目标

- 自动生成红字发票、供应商退款、税务平台单据或银行交易。
- 供应商 RMA/ASN、物流运单、运费分摊、PDA 扫码、序列号逐台追踪和图片附件。
- 已消耗物料反向拆解、跨收货批次自动分配或退货换货运输跟踪。
