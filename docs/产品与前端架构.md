# GuanSeq 产品与前端架构

> 系统级技术选型、后端、数据库、物联网、AI、安全、部署和建设路线统一见 [系统总体架构与开发蓝图](./系统总体架构.md)。当前前端完成度、缺失栏目与整改顺序见 [前端产品完整性审计](./前端产品审计.md)。本文继续记录前端产品边界。

## 产品定位

贯序是面向普通制造企业的专业级一体化制造运营管理平台。产品对用户表现为一个系统，内部保留清晰的事实归属：

- ERP：销售、采购、计划、MRP、应收应付和成本；
- MES：生产工单、工序执行、报工、在制品和追溯；
- WMS：仓库、库位、库存移动、领退料和盘点；
- QMS：检验标准、检验记录、不合格与质量追溯；
- PLM/PDM、APS、EAM：进入完整产品规划，后续分阶段深化。

## 第一条前端业务旅程

```text
销售订单
→ 生产计划 / MRP
→ 采购与备料
→ 生产工单
→ 工序执行与报工
→ 质量检验
→ 完工入库
→ 销售发货
→ 成本与订单利润（直接材料、工序人工、制造费用与毛利已贯通）
```

当前首页用于表达这条旅程的跨部门状态、责任、风险和执行证据，不代表正式业务事实已经落库。

## 前端分层

```text
页面与交互组件
        ↓
领域数据服务（src/services）
        ↓
运行时契约校验（Zod）
        ↓
已接入页面：OpenAPI Adapter → Java 业务核心
其余页面：Mock Adapter（逐项替换）
```

页面不得直接依赖散落的 JSON。后端接入后，由正式 API 适配器替换 Mock Adapter，页面继续使用相同的 TypeScript 契约。

## 页面与路由

- 一级、二级和三级菜单均使用稳定英文 URL；
- URL 是当前页面和左侧展开状态的唯一来源；
- 页面支持刷新、浏览器前进后退和复制链接直接访问；
- 例如：`/product/materials/list`、`/product/boms/list`、`/production/orders/list`；
- 未声明的路径返回标准 404，不回退到错误栏目。

## 当前可操作范围

- 12 个制造企业一级工作栏目及其功能地图；
- 桌面端一级、二级及按需三级左侧树形导航；
- 一级栏目手风琴式展开，避免全部功能同时铺开；
- 手机端使用左侧导航抽屉；
- 订单到交付主流程、经营指标、产能和交付风险；
- 生产工单列表与执行证据抽屉；
- 真实生产订单、生产报工、完工检验与合格品入库证据链；
- 真实设备台账、人工受控运行状态、一次性点检/保养、维修验收、维修备件成本、周期维护模板、人工到期生成、逾期风险和不可变事件证据链；Modbus TCP 与外部 MQTT 3.1.1 Broker 只读采集、有限样本历史、工作区保留策略、人工清理、受控自动运行、结构化技术预检和基础报警责任闭环已完成代码和标准协议仿真闭环，真实设备/Broker、现场阈值与现场验收待完成；
- 全局搜索及 `Ctrl/Command + K`、`Esc` 快捷键；
- Mock 数据运行时 Schema 校验与单元测试。
