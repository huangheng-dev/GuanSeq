# 最小组织层级与成员归属

> 状态：已实现（R1 第三项，2026-08-28）
>
> 正式页面：`/settings/organization/structure`
>
> 权限：仅当前工作区 `ADMIN`

## 1. 目标与边界

本切片把既有 `COMPANY → PLANT/SITE → workspace → membership` 数据从“只能首次初始化写入”提升为可查询、可审计、可并发保护的正式治理能力。它解决当前工作区的组织责任、工作区负责人和成员主要归属，不建设租户级超级管理员或通用权限引擎。

当前工作区管理员可以：

- 查询公司根、当前工作区所在组织、该工厂直属 `SITE`、当前工作区和成员归属；
- 修改当前所在组织或直属现场单元的名称与负责人；
- 在当前所在 `PLANT` 下创建、停用或恢复直属 `SITE`；
- 修改当前工作区名称与负责人；
- 将当前工作区成员归属到所在组织或启用的直属 `SITE`。

当前切片明确不提供：

- 公司根组织修改、其他工厂或其他工作区治理；
- 任意深度部门树、拖拽移动、物理删除、岗位编制；
- 自定义角色、组合权限、动态数据范围或 IdP 组同步；
- 由“负责人”或“组织归属”自动产生业务授权。

## 2. 业务规则

- 公司根在当前工作区只读，避免把工作区 `ADMIN` 扩张为租户级管理员。
- 只有当前所在组织为 `PLANT` 时才允许建立直属 `SITE`；编码创建后不可修改，层级不可移动。
- 负责人必须是当前工作区启用成员；负责人只是责任事实，不改变角色权限。
- 成员只能归属到当前所在组织或其启用直属 `SITE`；调整归属不改变成员角色。
- 现场单元不物理删除。仍有当前工作区启用成员或仍承载启用工作区时，停用返回 `409`。
- 组织、工作区和成员关系均使用乐观锁；过期版本返回 `409`，客户端必须刷新后重试。
- 创建、更新、停用/恢复和成员归属调整均记录操作者、工作区、请求编号、原因/前后值和发生时间。

## 3. 数据、API 与失败语义

- Flyway V57 为 `organization_units`、`workspaces` 增加负责人和版本，为 `workspace_memberships` 增加非空组织归属；既有成员从工作区所在组织回填。
- OpenAPI 事实入口为 `/api/v1/identity/organization-structure`，包含查询、现场单元创建/更新/状态、工作区更新和成员归属更新。
- 页面经同源 BFF 调用后端；后端不可用、无权限、校验失败、规则冲突和并发冲突均显示真实失败，不回退 Mock。
- `IDENTITY_ORGANIZATION_MANAGE` 纳入角色权限目录，当前仅 `ADMIN` 允许。

## 4. 验收条件

- 未认证返回 `401`，当前工作区非管理员返回 `403`。
- 空库可从 V1 迁移到 V57，既有成员归属完整回填。
- 管理员能创建直属现场、维护负责人和成员归属，并在刷新后读取一致事实。
- 有启用成员占用的现场单元不能停用；释放占用后可以停用，过期版本不能恢复。
- 所有成功写动作可通过请求编号查到审计事件。
- 正式页面进入真实性注册表；服务失败时失败关闭，不出现通用 Mock 操作。

## 5. 后续演进门禁

只有出现真实客户的跨工作区组织管理员、职责分离、部门级数据范围或组合权限证据时，才新增租户级授权 ADR。岗位、动态角色和组织数据范围必须分别建模，不能通过扩大当前 `ADMIN` 权限或把归属字段偷换成授权规则实现。
