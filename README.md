# GuanSeq（贯序）

贯序是面向普通制造企业的专业级一体化制造运营管理平台。产品统一规划 ERP、MES、WMS、QMS、PLM/PDM、APS、EAM、成本财务与数据分析能力。

当前前端产品基线已经收口，后端工程位于 `guanseq-server`。组织与工作区、客户和物料主数据、受控 BOM 与工艺路线版本、销售订单与独立需求、采购和生产订单、库存余额与不可变流水、物料提前期、MRP 净需求、MRP 建议审核转单，“生产报工 → 完工检验 → 合格品入库”，“生产备料/领料单生成 → 按 BOM 组件发料 → 库存扣减 → 已领组件退料 → 库存回补”，“生产订单下达 → 工序任务快照 → 开工/完工 → 实际人工登记审核 → 全部工序完成后报工”，采购收货与来料检验、销售发货与成品出库、销售应收开票与收款核销、采购应付发票与付款核销，以及订单收入、直接材料、实际人工、制造费用和毛利快照已经通过正式服务层接入真实 API；第一条制造与基础收付款主闭环已贯通。其余业务页面仍通过统一数据服务访问 Mock 数据，后端将继续按制造业务优先级逐项替换 Mock Adapter。

MRP 当前会冻结需求、库存、采购/生产计划接收与提前期快照，执行按日期净算、BOM 展开并形成采购、生产或委外建议；建议通过审核后可转为带来源追溯的采购或生产草稿单，不会自动下达。生产订单完工不允许直接改状态，工序任务未全部完成时不能报工，订单完工必须经过报工、质量判定和合格品入库形成审计证据。

## 当前范围

- 制造业一级、二级及按需三级左侧树形工作台
- 12 个一级栏目、119 个二级模块、97 个三级页面和 228 条独立产品路径
- 全路由专业页面目录、统一圆润表单/弹窗、分页、筛选、详情与业务状态
- 工作区切换、收藏与最近访问、全局搜索、通知中心和首页业务下钻
- 表单、刷新、查询、导出和规划反馈五类主操作语义
- 销售订单到生产交付的主流程总览
- 生产订单、产能负荷、质量异常和交付风险视图
- 加载、失败与数据适配边界的工程基线

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。

## 后端运行

```powershell
cd guanseq-server
docker compose up -d --wait postgres
.\mvnw.cmd spring-boot:run
```

后端默认运行在 `http://localhost:8080`，当前真实接口覆盖平台状态、工作区、主数据、BOM 与工艺路线、销售订单、独立需求、采购/生产订单、库存余额与流水、MRP 净需求、采购收货与来料检验、生产备料与领退料、车间工序执行、实际人工工时、生产报工和完工检验、销售发货与成品出库、销售应收开票与收款核销、采购应付发票与付款核销、订单利润结算。前端通过同源 BFF 路由代理访问后端，开发身份凭据不会进入浏览器代码。首次运行 Maven Wrapper 和 PostgreSQL 容器会下载对应的官方发行包。

后端完整说明见 [guanseq-server/README.md](./guanseq-server/README.md)。
